Decision story

EmTalk / Founder / Product Owner

Try before installing: bringing EmTalk's first value to the browser

Clicking Download does not mean someone has received value. I chose to let visitors try the core BRET or Decision Matrix flow directly on the website first.

Guest web flows added

BRET breathing and muscle-relaxation practices, plus Decision Matrix comparisons and weighted pros and cons, are available in the browser without registration.

Implementation and publication are described from project records dated 16-18 October 2026. First value is the flow's intended goal; user impact, uplift and a completed A/B test are not claimed.

Intended path to first value

  1. Understand the tool's purpose
  2. Open a guest flow
  3. Complete a practice or exercise
  4. Reach an understandable outcome
  5. Choose whether to continue

Reconsider what counts as conversion

A website could explain an app well and lead to a download, while the path to value remained inside another product. I wanted to focus on the person's outcome: completing a practice or structuring a decision. That changed the site's job. It should let people experience the proposed value as well as explain it.

Remove installation from the required path to a trial

We brought bounded guest flows into the browser. In BRET, a visitor can select a breathing rhythm or follow muscle relaxation. In Decision Matrix, they can compare options, examine pros and cons and see the calculated result. They can start without registration or installation. This reduces required steps before a trial; its effect on behaviour still needs measurement.

Offer a complete action within explicit limits

I agreed a free guest core, leaving authentication, subscriptions and server-side AI for a separate stage. Web DM calculates results in the browser and supports local saving, import and export. Local data does not become a cloud account. BRET provides pause, resume and a clear ending. The aim was a working flow without implying that every app capability was ready on the web.

From a first click to value we can investigate

For further evaluation, I distinguish opening the tool, starting, completing and returning. These are separate stages rather than one download conversion. For a practice, we need to understand whether someone can start and finish it; for DM, whether they can reach and understand the result. This is an intended evaluation model, not measured funnel values or evidence of improved wellbeing.

What this stage delivered

EmTalk gained a browser path to its core exercises. It was first checked in a separately published version and then developed on the main site. A visitor can try the tool before deciding to install. Activation and conversion gains have not yet been established: making the flow available enables research into its effect, but does not replace that research.
