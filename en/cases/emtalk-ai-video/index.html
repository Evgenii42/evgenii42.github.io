From carousel to video, with room for human intervention

The model proposes scenes, but does not decide on its own what reaches the final video. EmTalk's pipeline checks the plan in code and allows an individual scene to be replaced manually.

Active pipeline definition, output awaits QC

The n8n configuration connects source slides to a video assembled with captions and voiceover. A manual scene replacement path complements automation; the resulting file awaits quality control.

Based on tool configuration inspected on 10 October 2026. This describes the team workflow; execution outcomes and resource savings were not measured in this review.

How material moves through the pipeline

  1. Source carousel and slide goals
  2. An LLM proposes a scene plan
  3. Code checks source alignment and format
  4. Automatic or manual scene preparation
  5. Captions, voiceover and FFmpeg assembly
  6. The resulting file awaits quality control

Every scene needs a source

Our pipeline starts with prepared slides, each with an image, a role and a goal. A model turns them into a video plan. Code then matches scenes to source identifiers, rejects unknown and duplicate scenes, and restores missing ones. Duration, allowed camera movements and narration length are checked separately from the model's response.

Automation with a manual route

Each scene has its own state. A router selects the next step: source preparation, rendering, collecting the result or postproduction. The manual path skips automatic generation: an operator can prepare animation elsewhere, upload the result and return the scene to the pipeline. Rebuilding with a replacement for a selected scene is also supported.

Bring the parts together

Final assembly requires the expected number of ready scenes and an audio track. FFmpeg normalises image and audio formats, adds captions and an outro. The configuration includes a decoding check and a duration check on the resulting file.

A ready file still needs a decision

The final status means that the video has been assembled, while quality control is pending. Publishing is outside this stage. That boundary matters: structural checks help assemble material according to rules, but do not replace a judgement about whether it works for the viewer.
